# Waterfall Wipe

Blocks of the second clip pour down from above the frame column after column, like a waterfall: in each column they fall one behind the other, land with a small bounce and stack up from the bottom, casting soft shadows on the first clip until the stack fills the frame. Drive `progress` from 0 to 1.

Port of [`WaterfallWipe.glsl`](https://github.com/gl-transitions/gl-transitions/blob/master/transitions/WaterfallWipe.glsl) from [gl-transitions](https://github.com/gl-transitions/gl-transitions), by gre, under the MIT license (see [LICENSE](LICENSE)). The shader is rewritten in WGSL; it keeps the original's coordinates (y up) and shows the exact clips at `progress` 0 and 1.

## Inputs

- `first`: Outgoing clip
- `second`: Incoming clip (must have the same size as the first input)

## Output

Same size as the first input (`first`). Pixel format: the input's, when the effect may output it (the manifest has no `output` rule).

## Options

Written inline after the package name: `waterfall-wipe.zip=name=value`. Several options are separated by `&` in an FFmpeg `graph='...'` string (`:` also works but must be written `\:` there) or by `:` in `gpufx run`. A value is a literal or an FFmpeg expression in `t`, `n`, `w`, `h`, `a`, `sar`, `dar`; commas inside an FFmpeg command line are escaped as `\,`. See the repo [README](https://github.com/tqk2811/FFmpegGpuFilter/blob/master/README.md) and [EFFECT_FORMAT](https://github.com/tqk2811/FFmpegGpuFilter/blob/master/docs/EFFECT_FORMAT.md).

| Name | Type | Default | Range | Description |
|------|------|---------|-------|-------------|
| `progress` | float | `0.5` | 0 to 1 | 0 = first clip, 1 = second clip |
| `columns` | int | `10` | 2 to 40 | Number of columns (the blocks stay about square, with at most 48 rows) |
| `stagger` | float | `0.45` | 0 to 0.8 | Share of the transition over which the columns start one after another (0 pours them all together) |
| `bounce` | float | `0.5` | 0 to 1 | How high the blocks bounce as they land |
| `shadow` | float | `0.5` | 0 to 1 | Darkness of the shadows and of the edges of the falling blocks |
| `reverse` | bool | `false` | - | The columns pour from right to left instead of left to right |

An `int` is rounded to the nearest whole number.

## Example

```sh
ffmpeg -init_hw_device vulkan=vk:0,disable_multiplane=1 -filter_hw_device vk -i a.mp4 -i b.mp4 -filter_complex \
  "[0][1]gpufx=graph='waterfall-wipe.zip=progress=clip((t-1)/1.5\,0\,1)',hwdownload,format=yuv420p" out.mp4
```

Direct3D 12 (Windows):

```sh
ffmpeg -init_hw_device d3d12va=dx -filter_hw_device dx -i a.mp4 -i b.mp4 -filter_complex \
  "[0][1]gpufx=graph='waterfall-wipe.zip=progress=clip((t-1)/1.5\,0\,1)',hwdownload,format=nv12" out.mp4
```

The effect runs on every backend the filter supports (Vulkan, D3D12/D3D11, Metal on macOS); see the [README](https://github.com/tqk2811/FFmpegGpuFilter/blob/master/README.md).
